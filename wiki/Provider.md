# nxs-anomaly Provider

Manage [nxs-anomaly](https://github.com/nixys/nxs-anomaly) alerting and on-call
configuration as code. The Registry source is `nixys/nxs-anomaly`; use the local
name `anomaly` for the `anomaly_*` resources and data sources.

Requires Terraform 1.0 or later and a compatible nxs-anomaly `/api/v1/` API.
Authenticate with an API key. Explicit provider attributes override environment
variables. API keys and sensitive resource values can be stored in Terraform
state, so use a backend with appropriate access controls.

## Example Usage

```terraform
terraform {
  required_providers {
    anomaly = {
      source  = "nixys/nxs-anomaly"
      version = "~> 0.1"
    }
  }
}

provider "anomaly" {
  # URL of the nxs-anomaly API.
  # Can also be set via NXS_ANOMALY_URL environment variable.
  url = "http://localhost:8080"

  # API key for authentication.
  # Can also be set via NXS_ANOMALY_API_KEY environment variable.
  api_key = var.anomaly_api_key
}

variable "anomaly_api_key" {
  type      = string
  sensitive = true
  default   = ""
}
```
